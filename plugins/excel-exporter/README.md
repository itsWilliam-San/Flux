* Sancad 2 Excel
Esse é um programa especifico que desenvolvi para conseguir exportar dados do Sancad (e uma parta da topografia) em um template excel usado pela
empresa *GHX* que por sua vez entrega ela para a *Sanepar*.

Ele é feito para funcionar **apenas** no template que vem com esse plugin.

O funcionamento dele é local e foi pensado para funcionar junto com o programa ***Flux**.

Como ele é feito para um alvo especifico, que tem uma entrega especifica, esse plugin não receberá atualizações
para suportar outros formato, ou templates, ou features que não sejam essencial para a geração do arquivo final.
